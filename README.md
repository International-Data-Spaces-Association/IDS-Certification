# IDS-Certification
Welcome to the IDS Certification page on GitHub!

# Overview
This repository hosts the certification scheme and the rules of procedure for IDS Certification, the certification framework maintained by the International Data Spaces Association (IDSA) for IDS connectors.

IDS Certification verifies conformance to IDS Criteria through a modular, third-party evaluation mechanism.
